# 전현수 디지털 명함

예수인교회 전현수 목사의 디지털 명함입니다.

- 사이트: https://hyunsoo1713-dot.github.io/hyunsoo-card/
- 배포: GitHub Pages, `main` 브랜치의 `/docs` 폴더
- 미리보기 사진: 명함 맨 위 사진 원본 (`docs/profile.jpg`)

`docs/index.html`을 수정하고 `main` 브랜치에 push하면 자동 배포됩니다.
미리보기 사진을 변경할 때는 `og:image`와 `twitter:image`를 함께 바꿉니다.
카카오톡에 이전 미리보기가 남아 있다면 카카오디벨로퍼스 도구의 OG 캐시 초기화를 사용합니다.
